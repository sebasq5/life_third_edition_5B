## ✨ Características

- **Quiz personalizado** — Elige bloque temático, dirección de traducción y cantidad de preguntas.
- **Examen de 25** — Simula el examen con las 25 palabras más probables y un cronómetro de 12:30.
- **Directorio de repaso** — Tablas completas con Inglés / Español / Significado agrupadas por bloque.
- **Resultados detallados** — Porcentaje de aciertos, tiempo utilizado y revisión de errores.
- **Modo bilingüe** — Interfaz disponible en Español e Inglés (toggle ES / EN).
- **100% Responsive** — Funciona en móvil, tablet y escritorio.
